# VBN
This repository contains a demo script for a the vision-based navigation algorithm developed during my internship at ESA from April to September 2026. It includes the algorithm source code (tracking_mode.py and pose_estimation.py), a Jupyter notebook to orchestrate the different parts of the image processing algorithm, 2 small datasets of synthetic images to test the algorithm on and a results repository which includes the pose estimation results obtained on the full datasets.
